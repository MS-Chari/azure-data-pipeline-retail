# Azure Data Engineering Pipeline – Retail Sales

This project demonstrates an end-to-end data engineering solution using Azure services:
- **ADF** for ingestion from Azure Blob
- **Databricks** with PySpark for transformation
- **Azure SQL DB** as data sink
- **Power BI** for reporting

## Folder Structure
- `data/raw/`: Contains sample CSV files
- `notebooks/`: Databricks PySpark notebook
- `pipelines/`: ADF pipeline definition
- `powerbi/`: Placeholder for .pbix dashboard

> Sample data is synthetic and for demo purposes only.
